# Portfolio — Clément Simier

Portfolio statique prêt pour GitHub Pages.

## Fichiers
- `index.html` : structure et contenu
- `style.css` : design responsive
- `script.js` : menu mobile + animations
- `photo.jpg` : portrait fourni
- `CV-Clement-Simier.pdf` : CV fourni

## Déploiement GitHub Pages
1. Créer un dépôt GitHub, par exemple `clement-simier.github.io`.
2. Mettre tous les fichiers à la racine du dépôt.
3. Dans Settings → Pages, choisir le déploiement depuis la branche principale (`main`) et le dossier `/root`.
4. Le site sera servi par GitHub Pages.

Le contenu a été adapté à une candidature en Suisse romande / canton de Genève : titre métier clair, mobilité, permis/véhicule, compétences techniques, expérience chiffrée et présentation concise.
